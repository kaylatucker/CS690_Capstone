# DASC 690 Capstone — Olist

## Working title
Seller Performance & Customer Experience Analysis in E-Commerce

## Working research question
Which operational, product, and geographic factors are most strongly associated with seller performance and customer satisfaction in the Olist Brazilian e-commerce marketplace?

## Current scope
- Business focus: seller performance and customer experience
- Dataset: Olist Brazilian E-Commerce Public Dataset
- Main approach: business data analysis and visualization, supported by statistical methods where appropriate
- Tools: Python and SQL; Tableau/Power BI only if it feels beneficial for communicating results
- Course pipeline: Ask → Discover → Prepare → Analyze → Communicate
